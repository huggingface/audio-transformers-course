# Unidade 1. Trabalhando com dados de áudio

## O que você aprenderá nesta unidade

Toda tarefa de áudio ou fala começa com um arquivo de áudio. Antes de resolver essas tarefas, é importante entender o que esses arquivos contêm e como trabalhar com eles.

Nesta unidade, você conhecerá os termos fundamentais relacionados a dados de áudio, incluindo forma de onda, taxa de amostragem e espectrograma. Também aprenderá a trabalhar com conjuntos de dados de áudio: carregar e pré-processar os dados e acessar conjuntos grandes de maneira eficiente por streaming.

Ao final desta unidade, você dominará a terminologia essencial dos dados de áudio e terá as habilidades necessárias para trabalhar com conjuntos de dados de áudio em diferentes aplicações. Esses conhecimentos servirão de base para compreender o restante do curso.
