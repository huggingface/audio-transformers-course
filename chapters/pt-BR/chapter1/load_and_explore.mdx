# Carregue e explore um conjunto de dados de áudio

Neste curso, usaremos a biblioteca 🤗 Datasets para trabalhar com conjuntos de dados de áudio. 🤗 Datasets é uma biblioteca de código aberto para baixar e preparar conjuntos de dados de todas as modalidades, incluindo áudio. Ela oferece acesso fácil a uma seleção incomparável de conjuntos de dados de aprendizado de máquina disponíveis publicamente no Hugging Face Hub. Além disso, inclui diversos recursos específicos para áudio que simplificam o trabalho de pesquisadores e profissionais.

Para começar a trabalhar com conjuntos de dados de áudio, instale a biblioteca 🤗 Datasets e suas dependências para áudio:

```bash
pip install datasets[audio] soundfile librosa torchcodec
```

Uma das principais características de 🤗 Datasets é a possibilidade de baixar e preparar um conjunto de dados com uma única linha de Python, usando a função `load_dataset()`.

Vamos carregar e explorar um conjunto de dados de áudio chamado [MINDS-14](https://huggingface.co/datasets/PolyAI/minds14), que contém gravações de pessoas fazendo perguntas a um sistema de banco eletrônico em vários idiomas e dialetos.

Para carregar o MINDS-14, copie seu identificador no Hub (`PolyAI/minds14`) e passe-o à função `load_dataset`. Também especificaremos que queremos apenas o subconjunto australiano (`en-AU`) e somente a divisão de treinamento:

```py
from datasets import load_dataset

minds = load_dataset("PolyAI/minds14", name="en-AU", split="train")
minds
```

**Saída:**
```out
Dataset(
    {
        features: [
            "path",
            "audio",
            "transcription",
            "english_transcription",
            "intent_class",
            "lang_id",
        ],
        num_rows: 654,
    }
)
```

O conjunto contém 654 arquivos de áudio, cada um acompanhado de uma transcrição, uma tradução para o inglês e um rótulo que indica a intenção da pergunta. A coluna de áudio contém os dados brutos. Vamos examinar um dos exemplos:

```py
example = minds[0]
example
```

**Saída:**
```out
{
    "path": "/root/.cache/huggingface/datasets/downloads/extracted/f14948e0e84be638dd7943ac36518a4cf3324e8b7aa331c5ab11541518e9368c/en-AU~PAY_BILL/response_4.wav",
    "audio": {
        "path": "/root/.cache/huggingface/datasets/downloads/extracted/f14948e0e84be638dd7943ac36518a4cf3324e8b7aa331c5ab11541518e9368c/en-AU~PAY_BILL/response_4.wav",
        "array": array(
            [0.0, 0.00024414, -0.00024414, ..., -0.00024414, 0.00024414, 0.0012207],
            dtype=float32,
        ),
        "sampling_rate": 8000,
    },
    "transcription": "I would like to pay my electricity bill using my card can you please assist",
    "english_transcription": "I would like to pay my electricity bill using my card can you please assist",
    "intent_class": 13,
    "lang_id": 2,
}
```

A coluna de áudio contém vários campos:

* `path`: o caminho do arquivo de áudio (`*.wav`, neste caso).
* `array`: os dados de áudio decodificados, representados por um array NumPy unidimensional.
* `sampling_rate`: a taxa de amostragem do arquivo de áudio, de 8.000 Hz neste exemplo.

O campo `intent_class` é a categoria de classificação da gravação. Para converter esse número em uma string com significado, podemos usar o método `int2str()`:

```py
id2label = minds.features["intent_class"].int2str
id2label(example["intent_class"])
```

**Saída:**
```out
"pay_bill"
```

Se examinar o campo de transcrição, você verá que o arquivo de áudio contém, de fato, uma pessoa perguntando sobre o pagamento de uma conta.

Para treinar um classificador de áudio nesse subconjunto, talvez você não precise de todos os campos. Por exemplo, `lang_id` terá o mesmo valor em todos os exemplos e não será útil. Nesse subconjunto, `english_transcription` provavelmente repetirá o conteúdo de `transcription`, então podemos remover esses campos com segurança.

É fácil remover campos desnecessários com o método `remove_columns` de 🤗 Datasets:

```py
columns_to_remove = ["lang_id", "english_transcription"]
minds = minds.remove_columns(columns_to_remove)
minds
```

**Saída:**
```out
Dataset({features: ["path", "audio", "transcription", "intent_class"], num_rows: 654})
```

Agora que carregamos e examinamos o conteúdo bruto do conjunto de dados, vamos ouvir alguns exemplos! Usaremos os recursos `Blocks` e `Audio` de `Gradio` para decodificar algumas amostras aleatórias:

```py
import gradio as gr


def generate_audio():
    example = minds.shuffle()[0]
    audio = example["audio"]
    return (
        audio["sampling_rate"],
        audio["array"],
    ), id2label(example["intent_class"])


with gr.Blocks() as demo:
    with gr.Column():
        for _ in range(4):
            audio, label = generate_audio()
            output = gr.Audio(audio, label=label)

demo.launch(debug=True)
```

```py
import librosa

librosa.display.waveshow(array, sr=sampling_rate)
```
