# Boas-vindas ao curso de áudio da Hugging Face!

Olá!

Boas-vindas a este curso sobre o uso de transformers para áudio. Os transformers têm demonstrado repetidamente que estão entre as arquiteturas de aprendizado profundo mais poderosas e versáteis, capazes de alcançar resultados do estado da arte em uma ampla variedade de tarefas, incluindo processamento de linguagem natural, visão computacional e, mais recentemente, processamento de áudio.

Neste curso, vamos explorar como aplicar transformers a dados de áudio. Você aprenderá a usá-los para resolver diversas tarefas relacionadas a áudio. Se seu interesse é reconhecimento de fala, classificação de áudio ou geração de fala a partir de texto, os transformers e este curso têm o que você precisa.

Ao longo do curso, você entenderá as particularidades do trabalho com dados de áudio, conhecerá diferentes arquiteturas de transformers e treinará seus próprios transformers para áudio usando modelos pré-treinados poderosos.

Este curso foi elaborado para estudantes que tenham conhecimentos de aprendizado profundo e familiaridade geral com transformers. Não é necessário ter experiência em processamento de dados de áudio. Se precisar revisar seus conhecimentos sobre transformers, confira nosso [curso de processamento de linguagem natural (NLP)](https://huggingface.co/course/chapter1/1), que aborda seus fundamentos em detalhes.

## Estrutura do curso

O curso está organizado em várias unidades que abordam diferentes assuntos em profundidade:

* [Unidade 1](https://huggingface.co/learn/audio-course/chapter1): conheça as particularidades do trabalho com dados de áudio, incluindo técnicas de processamento de áudio e preparação de dados.
* [Unidade 2](https://huggingface.co/learn/audio-course/chapter2): conheça aplicações de áudio e aprenda a usar pipelines de 🤗 Transformers para diferentes tarefas, como classificação de áudio e reconhecimento de fala.
* [Unidade 3](https://huggingface.co/learn/audio-course/chapter3): explore arquiteturas de transformers para áudio, entenda suas diferenças e descubra para quais tarefas cada uma é mais adequada.
* [Unidade 4](https://huggingface.co/learn/audio-course/chapter4): aprenda a criar seu próprio classificador de gêneros musicais.
* [Unidade 5](https://huggingface.co/learn/audio-course/chapter5): aprofunde-se em reconhecimento de fala e crie um modelo para transcrever gravações de reuniões.
* [Unidade 6](https://huggingface.co/learn/audio-course/chapter6): aprenda a gerar fala a partir de texto.
* [Unidade 7](https://huggingface.co/learn/audio-course/chapter7): aprenda a criar aplicações reais de áudio com transformers.

Cada unidade inclui uma parte teórica para que você compreenda profundamente os conceitos e as técnicas envolvidos. Ao longo do curso, oferecemos questionários para testar seus conhecimentos e reforçar o aprendizado. Alguns capítulos também incluem exercícios práticos para você aplicar o que aprendeu.

Ao final do curso, você terá uma base sólida no uso de transformers para dados de áudio e estará bem preparado para aplicar essas técnicas a uma ampla variedade de tarefas relacionadas a áudio.

As unidades do curso serão lançadas em blocos consecutivos, seguindo este cronograma de publicação:

## Trilhas de aprendizado e certificação

Não há uma maneira certa ou errada de fazer este curso. Todos os materiais são 100% gratuitos, públicos e de código aberto. Você pode estudar no seu próprio ritmo, mas recomendamos seguir a ordem das unidades.

Se quiser receber um certificado ao concluir o curso, oferecemos duas opções:

| Tipo de certificado | Requisitos |
|---|---|
| Certificado de conclusão | Concluir 80% dos exercícios práticos conforme as instruções. |
| Certificado com honras | Concluir 100% dos exercícios práticos conforme as instruções. |

Cada exercício prático apresenta seus critérios de conclusão. Quando tiver concluído exercícios suficientes para obter um dos certificados, consulte a última unidade do curso para saber como recebê-lo. Boa sorte!
