# Prepare-se para fazer o curso

Esperamos que você esteja com vontade de começar! Preparamos esta página para garantir que você tenha tudo de que precisa para entrar no curso.

## Passo 1. Inscreva-se

Inscreva-se no curso para acompanhar todas as atualizações e os eventos especiais da comunidade.

[👉 INSCREVA-SE](http://eepurl.com/insvcI)

## Passo 2. Crie uma conta na Hugging Face

Se você ainda não tem uma conta na Hugging Face, crie uma: é gratuito. Você precisará dela para realizar as atividades práticas, receber seu certificado de conclusão, explorar modelos pré-treinados, acessar conjuntos de dados e muito mais.

[👉 CRIE UMA CONTA NA HUGGING FACE](https://huggingface.co/join)

## Passo 3. Revise os fundamentos, se necessário

Pressupomos que você conheça os fundamentos de aprendizado profundo e tenha familiaridade geral com transformers. Se precisar revisar seus conhecimentos sobre transformers, confira nosso [curso de processamento de linguagem natural (NLP)](https://huggingface.co/course/chapter1/1).

## Passo 4. Confira seu ambiente

Para acompanhar os materiais do curso, você precisará de:

- Um computador com conexão à internet.
- [Google Colab](https://colab.research.google.com) para os exercícios práticos. A versão gratuita é suficiente. Se você nunca usou o Google Colab, confira este [notebook oficial de introdução](https://colab.research.google.com/notebooks/intro.ipynb).

<Tip>

Como alternativa à versão gratuita do Google Colab, você pode usar seu próprio ambiente local ou o Kaggle Notebooks. O Kaggle Notebooks oferece uma quantidade fixa de horas de GPU e funcionalidades semelhantes às do Google Colab. No entanto, há diferenças no compartilhamento de modelos no 🤗 Hub, por exemplo, para concluir as atividades. Se optar pelo Kaggle Notebooks, confira o [notebook de exemplo do Kaggle](https://www.kaggle.com/code/michaelshekasta/test-notebook) criado por [@michaelshekasta](https://github.com/michaelshekasta). Ele mostra como treinar e compartilhar seu modelo treinado no 🤗 Hub.

</Tip>

Entre em nosso servidor do Discord para trocar ideias com outros estudantes e entrar em contato conosco, a equipe da Hugging Face.

[👉 JUNTE-SE À COMUNIDADE NO DISCORD](http://hf.co/join/discord)
