# Leituras e recursos adicionais

Esta unidade apresentou a síntese de fala a partir de texto e abordou muitos assuntos. Quer aprender mais? Estes recursos ajudam a aprofundar os temas e enriquecer seu aprendizado.

* [HiFi-GAN: redes adversariais generativas para síntese de fala eficiente e de alta fidelidade](https://arxiv.org/pdf/2010.05646.pdf): artigo que apresenta HiFi-GAN para síntese de fala.
* [X-Vectors: embeddings robustos de redes profundas para reconhecimento de falante](https://www.danielpovey.com/files/2018_icassp_xvectors.pdf): artigo que apresenta o método X-Vector para embeddings de falante.
* [FastSpeech 2: síntese de fala a partir de texto rápida, de alta qualidade e de ponta a ponta](https://arxiv.org/pdf/2006.04558.pdf): artigo que apresenta FastSpeech 2, outro modelo TTS popular, que usa um método não autorregressivo.
* [Uma abordagem com quantização vetorial para síntese de fala a partir de texto em fala espontânea do mundo real](https://arxiv.org/pdf/2302.04215v1.pdf): artigo que apresenta MQTTS, um sistema TTS autorregressivo que substitui espectrogramas mel por uma representação discreta quantizada.
