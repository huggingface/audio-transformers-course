# Crie uma demonstração com Gradio

Agora que ajustamos Whisper para reconhecimento de fala em dhivehi, vamos criar uma demonstração com [Gradio](https://gradio.app) para apresentá-lo à comunidade!

Primeiro, carregamos o checkpoint ajustado com `pipeline()`, como já vimos na seção de [modelos pré-treinados](asr_models). Você pode trocar `model_id` pelo identificador de seu modelo no Hub ou por um dos [modelos Whisper](https://huggingface.co/models?sort=downloads&search=openai%2Fwhisper-) pré-treinados para realizar reconhecimento de fala zero-shot:

```python
from transformers import pipeline

model_id = "sanchit-gandhi/whisper-small-dv"  # update with your model id
pipe = pipeline("automatic-speech-recognition", model=model_id)
```

Depois, definimos uma função que recebe o caminho de um arquivo de áudio e o passa ao pipeline. Ele cuida automaticamente do carregamento, da reamostragem para a taxa correta e da inferência. Basta retornar o texto transcrito como saída. Para processar entradas de qualquer duração, ativaremos a *divisão em segmentos* descrita na seção de [modelos pré-treinados](asr_models):

```python
def transcribe_speech(filepath):
    output = pipe(
        filepath,
        max_new_tokens=256,
        generate_kwargs={
            "task": "transcribe",
            "language": "sinhalese",
        },  # update with the language you've fine-tuned on
        chunk_length_s=30,
        batch_size=8,
    )
    return output["text"]
```

Usaremos o recurso [Blocks](https://gradio.app/docs/#blocks) de Gradio para criar duas abas: uma para transcrição pelo microfone e outra para envio de arquivos.

```python
import gradio as gr

demo = gr.Blocks()

mic_transcribe = gr.Interface(
    fn=transcribe_speech,
    inputs=gr.Audio(sources="microphone", type="filepath"),
    outputs=gr.components.Textbox(),
)

file_transcribe = gr.Interface(
    fn=transcribe_speech,
    inputs=gr.Audio(sources="upload", type="filepath"),
    outputs=gr.components.Textbox(),
)
```

Por fim, iniciamos a demonstração com os dois blocos definidos:

```python
with demo:
    gr.TabbedInterface(
        [mic_transcribe, file_transcribe],
        ["Transcribe Microphone", "Transcribe Audio File"],
    )

demo.launch(debug=True)
```
