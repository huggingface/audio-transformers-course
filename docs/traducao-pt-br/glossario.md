# Glossário de tradução para pt-BR

Use português brasileiro, tratamento por “você” e tom didático. Preserve nomes de bibliotecas, modelos, APIs e dados de exemplos. Nas primeiras ocorrências, inclua o termo inglês quando ajudar a reconhecer a expressão técnica. Siglas permanecem no original.

| --- | --- |
| deep learning | aprendizado profundo |
| machine learning | aprendizado de máquina |

| self-attention | autoatenção |

Não traduzir transcrições, entradas de modelos, saídas reproduzidas ou nomes de campos para uniformizar a linguagem: esses elementos podem ser necessários à reprodução dos resultados. Traduzir comentários e mensagens de apresentação somente quando não alterar comportamento. Registrar decisões novas aqui e conferir sua aplicação nas seções já revisadas.
