# Glossário de tradução para pt-BR

Use português brasileiro, tratamento por “você” e tom didático. Preserve nomes de bibliotecas, modelos, APIs e dados de exemplos. Nas primeiras ocorrências, inclua o termo inglês quando ajudar a reconhecer a expressão técnica. Siglas permanecem no original.

| Termo de referência | Forma adotada |
| --- | --- |
| deep learning | aprendizado profundo |
| machine learning | aprendizado de máquina |
| transformer | transformer (arquitetura); Transformers (biblioteca) |
| dataset | conjunto de dados |
| sample | amostra; exemplo, quando for uma entrada do conjunto de dados |
| sampling | amostragem |
| sampling rate | taxa de amostragem |
| resampling | reamostragem |
| waveform | forma de onda |
| frequency bin | faixa de frequência |
| spectrogram | espectrograma |
| log-mel spectrogram | espectrograma log-mel |
| feature | característica |
| feature extractor | extrator de características |
| embedding | embedding (representação vetorial) |
| encoder / decoder | codificador / decodificador |
| self-attention | autoatenção |
| cross-attention | atenção cruzada |
| pre-trained | pré-treinado |
| fine-tuning | ajuste fino |
| training / inference | treinamento / inferência |
| loss | perda; função de perda, conforme o contexto |
| checkpoint | checkpoint (estado salvo do modelo) |
| pipeline | pipeline |
| streaming | streaming (processamento ou acesso em fluxo, conforme o contexto) |
| automatic speech recognition (ASR) | reconhecimento automático de fala (ASR) |
| text-to-speech (TTS) | síntese de fala a partir de texto (TTS) |
| speech-to-speech translation | tradução de fala para fala |
| connectionist temporal classification (CTC) | classificação temporal conexionista (CTC) |
| word error rate (WER) | taxa de erro de palavras (WER) |
| character error rate (CER) | taxa de erro de caracteres (CER) |
| vocoder | vocoder |
| hands-on exercise | exercício prático |
| quiz | questionário |
| open-source | de código aberto |
| state-of-the-art | estado da arte |

Não traduzir transcrições, entradas de modelos, saídas reproduzidas ou nomes de campos para uniformizar a linguagem: esses elementos podem ser necessários à reprodução dos resultados. Traduzir comentários e mensagens de apresentação somente quando não alterar comportamento. Registrar decisões novas aqui e conferir sua aplicação nas seções já revisadas.
